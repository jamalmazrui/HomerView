HomerView: several tools in one browser, for JAWS and NVDA

HomerView is a free, open-source companion for reading the web with a screen reader on Windows. It runs Microsoft Edge under your own screen reader and adds the things that reading the web with JAWS or NVDA otherwise asks you to go elsewhere for.

A browser

Everything Microsoft Edge already does, read through your own screen reader. HomerView adds commands. It does not replace the browser or ask you to learn a new one.

An accessibility tester

One command checks the page with the axe engine. Another checks it with IBM’s. Each writes a report that names every rule the page broke, how serious it is, which parts of the page are at fault, and how to fix them.

The report is plain enough to send to the people who run the site, and exact enough for their developers to act on. That matters: a report a developer can act on gets more fixed than a complaint does.

A document and ebook reader

HomerView turns Word files, EPUB books, PDFs and other common formats into web pages, then opens them. Headings, lists, tables and links become real headings, lists, tables and links. So you move through a book or a report by heading, instead of reading a flat wall of text.

A file downloader

It finds the files a page points to, works out what each one is, and downloads the kinds you pick. It uses the browser’s own cookies, so pages you have signed in to still work.

Other tools

  • Main content pulls the article out of a page and opens it without the menus, banners and adverts.
  • Names lists the people, places, groups and dates a page mentions, which is a different question from what the page says.
  • Find and select text, list tabs and links, read a page’s hidden details, hear where a link really goes, and copy any of it.

JAWS and NVDA, equally

The two do the same things: the same commands, the same answers, the same pages. Keys differ only where the two screen readers themselves differ, so this announcement gives both keys only where they are not the same.

You will need one of:

  • JAWS, from Freedom Scientific
  • NVDA, from NV Access

Microsoft Edge is also required, and it is built into every modern Windows computer, so there is nothing to install. HomerView keeps its own browser profile, so your ordinary browsing is untouched.

Getting it

  • HomerView executable installer
  • HomerView project on GitHub

Run the installer and tick the box for the screen reader you use; it offers whichever it finds. Then press Alt+JAWS+H in JAWS, or Alt+NVDA+H in NVDA (the JAWS and NVDA modifier keys may be Insert or Caps Lock, whichever you have set). From there the menu key lists every command, and hot key help lists every key.
