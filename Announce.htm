HomerView: six tools in one browser, for JAWS and NVDA

  • A browser
  • An accessibility tester
  • A document and ebook reader
  • A web downloader
  • A main-content extractor
  • And smaller aids
  • JAWS and NVDA, equally
  • Getting it

HomerView is a free, open-source companion for reading the web with a screen reader on Windows. It runs Microsoft Edge under your own screen reader and adds six things that reading the web with JAWS or NVDA otherwise asks you to go elsewhere for.

A browser

Every native Edge feature, reached through your own browse mode. HomerView adds commands; it does not replace the browser or ask you to learn a new one.

An accessibility tester

One command runs the axe engine over the page in front of you; another runs IBM’s. Each writes a report naming every rule that failed, its severity, the elements involved and how to fix them. Plain enough to send to a publisher, specific enough for their developers to act on — which is the point, because a report a sighted developer can act on gets more fixed than a complaint can.

A document and ebook reader

DOCX, EPUB, PDF and other popular formats are converted to structured HTML and opened in the browser. Headings, lists, tables and links become real navigation in browse mode, so a book or a report is something you move through by heading rather than a flat wall of text.

A web downloader

It finds the files the current page points at — documents, images, media, scripts — works out what each one actually is, and fetches the kinds you choose, using the browser’s own cookies so a page you are signed in to still works.

A main-content extractor

One command lifts the article out of a page and opens it without the navigation, banners and advertising, links intact.

And smaller aids

Finding and selecting text, listing tabs and links, reading a page’s metadata, saying where a link really goes, and putting any of it on the clipboard.

JAWS and NVDA, equally

The two are at feature parity: the same commands, the same answers, the same generated pages. Keys differ only where each screen reader’s own conventions differ, so this announcement gives both only where they part company.

You will need one of:

  • JAWS, from Freedom Scientific: https://www.freedomscientific.com/products/software/jaws/
  • NVDA, from NV Access: https://www.nvaccess.org/download/

Microsoft Edge is required. HomerView keeps its own browser profile, so your ordinary browsing is untouched.

Getting it

HomerView is at https://github.com/JamalMazrui/HomerView. Run the installer and tick the box for the screen reader you use; it offers whichever it finds.

Then press Alt+Insert+H in JAWS, or Alt+NVDA+H in NVDA. From there the menu key lists every command and hot key help lists every key.
