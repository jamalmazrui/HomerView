# RepoFiles.txt -- what this repository carries beyond what the program installs.
#
# THIS FILE IS THE WHOLE LIST (26 September 2026). It used to be the second
# list after HomerView_setup.iss, whose Source lines counted too; the kit's
# tidy builds its whitelist from this file alone, so everything the repository
# carries is named here, the installed files included.
#
# TRACKED is what the repository keeps but the program does not install: the
# scripts that build, check and release it, and the sources they read.
#
# LOCAL is what lives on disk and is never committed: build output, logs, and
# working material. A name here is a promise that losing the file costs
# nothing, because the build makes it again.
#
# To keep a new file out of the repository, name it in neither list. That is
# how a file is excluded.
#
# A name here may take three shapes: a plain name, a folder ending in a
# backslash, or a pattern holding an asterisk. All three are still names,
# written down here on purpose, rather than a sweep guessing from an
# extension what a file is for. Until 31 August 2026 only the first shape
# was matched, so build\ and notes\ had been in this file from the start
# and had never matched anything.

# This file itself, which is the second of the two lists that decide what
# belongs here. A list that does not name itself is a stray by its own rule.
